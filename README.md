## Proyectos

### Planificador de Tareas · proyecto personal
Un gestor de tareas común muestra todo junto y abruma. Este planificador usa el enfoque **Kanban** para organizar según la urgencia, con prioridad (alta, media o baja), etiquetas y columnas que se pueden renombrar para adaptarlas, por ejemplo, a SCRUM. Es una herramienta que yo usaría en mi día a día.

- **Mi aporte:** lo diseñé y desarrollé completo, con mi propio estilo, y aplico SCRUM con tablero en GitHub Projects.
- **Desafío:** definir el mínimo producto viable: funciones posibles en el tiempo disponible, pero que de verdad ayudaran al usuario y fueran fáciles de navegar.
- **Estado:** frontend con persistencia en localStorage y pruebas unitarias con Jest; backend (Java, Spring Boot, MySQL) en planificación.
- **Tecnologías:** HTML · CSS · JavaScript · Jest · Java · Spring Boot · MySQL
- [Código](https://github.com/jbernalo18/Proyecto-Planificador-Tareas)

### Kit-Box · proyecto en equipo
Resuelve la frustración de las compras sueltas al empezar algo nuevo (adoptar una mascota, una mudanza, empezar a dibujar o a hacer ejercicio): reúne todo en kits completos. La idea fue mía y mi equipo la apoyó.

- **Equipo:** Dayana Vallejo, Cristian Rojas, Cristhian Beltran y Diana Ocampo, bajo SCRUM, con roles que rotaban cada semana.
- **Mi aporte:** fui Scrum Master en mi turno; creé la estructura del backend con Spring Initializr y la subí al repositorio (arquitectura por capas: controller, service, repository); diseñé y desarrollé la vista de administrador y armé el banner responsivo del catálogo.
- **Desafíos:** enlaces rotos, JWT, definir la identidad visual y encontrar el mínimo producto viable que fuera funcional y resolviera algo real.
- **Tecnologías:** HTML · CSS · JavaScript · Java · Spring Boot · JWT · MySQL · Figma · Git
- [Código](https://github.com/KristianKnt/kit-box)

### LoanRequest y bot RPA · proyecto de bootcamp
Los procesos manuales de solicitud de créditos tenían errores de redacción y costos de mantenimiento altos. En **Bizagi** modelé procesos, reglas y entidades, con autenticación y base de datos. En la parte de **RPA**, con Automation Anywhere y UiPath, un bot extrae datos de PDFs, arma el Excel y lo lleva a la base de datos. La eficiencia aumentó un 65 %, medida contra el tiempo que tardaba una persona en el proceso.

- **Lo que me dejó:** fue mi primer acercamiento a proyectos de desarrollo y me abrió la mente para entender cómo funciona todo conectado.
- **Tecnologías:** Bizagi Studio · BPMN · SQL Server Express · UiPath · Automation Anywhere
- [Código](https://github.com/jbernalo18/LoanRequest-y-RPA)
